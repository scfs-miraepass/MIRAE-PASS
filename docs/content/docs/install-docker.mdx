# Docker 설치 가이드

이 문서에서는 운영체제별 Docker와 Docker Compose v2를 설치 방법을 설명합니다.

    <Tabs.Tab>
        <Callout type="warning">
            이 문서에서는 Debian 계열의 Linux에서 설치하는 방법을 설명합니다.<br />
            다른 계열의 Linux의 경우 [Docker 공식 문서](https://docs.docker.com/engine/install)를 참고바랍니다.
        </Callout>

        ## 스크립트 설치
        자동으로 설치를 진행합니다. 개발및 테스트 환경에서 이용하며, 운영 환경에서는 [수동 설치](#수동-설치)를 권장합니다.
        ```bash
        sudo apt update
        sudo apt install ca-certificates curl
        curl -fsSL https://get.docker.com | sudo sh
        ```
        ## 수동 설치
        <Steps>
            ### (선택) 기존 Docker 삭제
            기존에 Docker를 설치 했던 경우, **반드시 삭제 후 진행해야 합니다.**<br />
            설치를 진행하지 않을 경우 다름 단계를 진행하세요. 설치하지 않았더라도 실행시 문제가 되진 않습니다.
            ```bash
            sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-doc docker-buildx podman-docker containerd runc | cut -f1)
            ```

            ### APT 저장소 등록
            ```bash
            sudo apt update
            sudo apt install ca-certificates curl
            sudo install -m 0755 -d /etc/apt/keyrings
            sudo curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
            sudo chmod a+r /etc/apt/keyrings/docker.asc

            sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
            Types: deb
            URIs: https://download.docker.com/linux/debian
            Suites: $(. /etc/os-release && echo "$VERSION_CODENAME")
            Components: stable
            Architectures: $(dpkg --print-architecture)
            Signed-By: /etc/apt/keyrings/docker.asc
            EOF

            sudo apt update
            ```

            ### Docker 설치
            ```bash
            sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
            ```

            ### 설치 검증하기
            설치가 완료 되었다면 아래의 명령어를 통해 테스트 해볼 수 있습니다.
            ```bash
            sudo docker run hello-world
            ```
            명령어를 실행 후, 몇 초뒤 아래와 같은 내용이 뜬다면 성공적으로 설치가 된 것입니다.
            ```
            Hello from Docker!
            ...(생략)
            ```
        </Steps>

        ## 설치 전 확인 사항
        설치를 시작하기 전에 내 컴퓨터가 아래 조건을 만족하는지 확인합니다.

        | 항목 | 조건 | 확인 방법 |
        | --- | --- | --- |
        | 운영체제 | Windows 10 (22H2 이상) 또는 Windows 11, **64비트** | `시작` 버튼 우클릭 → `시스템` → "Windows 사양"과 "시스템 종류" 확인 |
        | 메모리(RAM) | 4GB 이상 (8GB 이상 권장) | 위와 같은 화면의 "설치된 RAM" 확인 |
        | 가상화 | 사용(켜짐) 상태 | `Ctrl` + `Shift` + `Esc`로 작업 관리자 실행 → `성능` 탭 → `CPU` → "가상화: 사용" 확인 |

        <Callout type="warning">
            작업 관리자에서 **"가상화: 사용 안 함"** 으로 표시된다면, 컴퓨터의 BIOS 설정에서 가상화 기능(Intel VT-x 또는 AMD-V / SVM)을 켜야 합니다.<br />
            BIOS 진입 방법은 컴퓨터 제조사마다 다르므로, "제조사 이름 + BIOS 가상화 켜기"로 검색하거나 주변 선생님·선배에게 도움을 요청하세요.
        </Callout>

        ## Windows에 Docker Desktop 설치하기
        <Steps>
            ### WSL 2 설치하기
            **WSL**(Windows Subsystem for Linux)은 Windows 안에서 Linux를 실행할 수 있게 해주는 기능입니다.
            Docker는 원래 Linux에서 동작하는 프로그램이라, Windows에서는 이 기능을 이용해 실행됩니다.

            1. 키보드에서 `Win` 키를 누르고 **PowerShell** 을 검색합니다.
            2. 검색 결과에서 **Windows PowerShell** 에 마우스 우클릭 → **관리자 권한으로 실행** 을 누릅니다.
            3. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 라는 창이 뜨면 **예** 를 누릅니다.
            4. 파란색(또는 검은색) 창이 열리면 아래 명령어를 복사해 붙여넣고 `Enter` 를 누릅니다.

            ```powershell
            wsl --install
            ```

            설치가 끝나면 **컴퓨터를 재시작**합니다.

            <Callout type="info">
                이미 WSL이 설치되어 있다면 "이미 설치되어 있습니다" 같은 메시지가 나옵니다. 이 경우 그대로 다음 단계로 넘어가면 됩니다.<br />
                재시작 후 Ubuntu 창이 열리면서 사용자 이름과 비밀번호를 물어볼 수 있습니다. 원하는 영문 이름과 비밀번호를 입력하면 됩니다. (비밀번호는 입력해도 화면에 표시되지 않는 것이 정상입니다.)
            </Callout>

            ### 설치 파일 내려받기
            [Docker Desktop 다운로드 페이지](https://docs.docker.com/desktop/setup/install/windows-install/)에 접속해
            **Docker Desktop for Windows - x86_64** 버튼을 눌러 설치 파일(`Docker Desktop Installer.exe`)을 내려받습니다.

            <Callout type="info">
                대부분의 Windows 노트북·데스크톱은 **x86_64** 를 받으면 됩니다.<br />
                Surface Pro X, 갤럭시 북 엣지 같은 Snapdragon(ARM) 노트북을 사용하는 경우에만 **Arm (Beta)** 버전을 받습니다.
            </Callout>

            ### 설치 프로그램 실행하기
            1. 내려받은 `Docker Desktop Installer.exe` 를 더블클릭해 실행합니다.
            2. 설정 화면에서 **Use WSL 2 instead of Hyper-V (recommended)** 항목이 **체크되어 있는지** 확인하고 `OK` 를 누릅니다.
            3. 설치가 진행됩니다. 몇 분 정도 걸릴 수 있습니다.
            4. 설치가 끝나면 **Close and restart** (또는 `Close`) 버튼을 눌러 컴퓨터를 재시작합니다.

            ### Docker Desktop 처음 실행하기
            1. `Win` 키를 누르고 **Docker Desktop** 을 검색해 실행합니다.
            2. 서비스 약관(Docker Subscription Service Agreement) 창이 뜨면 **Accept** 를 누릅니다.
            3. 로그인/회원가입 화면이 나오면 **Skip** 을 눌러 건너뛰어도 됩니다. (설문 화면도 `Skip` 으로 건너뛸 수 있습니다.)
            4. 화면 왼쪽 아래에 **Engine running** 이라는 초록색 표시가 나타나면 Docker가 정상적으로 실행된 것입니다.

            <Callout type="warning">
                Docker 명령어를 사용할 때는 **항상 Docker Desktop이 실행 중이어야 합니다.**<br />
                컴퓨터를 켤 때마다 자동으로 실행되게 하려면 Docker Desktop의 `Settings`(톱니바퀴) → `General` → **Start Docker Desktop when you sign in to your computer** 를 체크하세요.
            </Callout>

            ### 설치 확인하기
            `Win` 키를 누르고 **PowerShell** 을 검색해 실행(관리자 권한 필요 없음)한 뒤, 아래 명령어를 한 줄씩 입력합니다.
            ```powershell
            docker --version
            docker compose version
            ```
            아래와 비슷하게 버전 정보가 나오면 설치가 잘 된 것입니다. (숫자는 달라도 괜찮습니다.)
            ```
            Docker version 28.x.x, build xxxxxxx
            Docker Compose version v2.x.x
            ```

            마지막으로 테스트용 프로그램을 실행해 봅니다.
            ```powershell
            docker run hello-world
            ```
            몇 초 뒤 아래와 같은 내용이 뜬다면 성공적으로 설치가 된 것입니다.
            ```
            Hello from Docker!
            ...(생략)
            ```
        </Steps>

        ## 자주 발생하는 문제
        - **`docker` 은(는) 내부 또는 외부 명령... 이 아닙니다** / **`docker` 용어가 cmdlet... 으로 인식되지 않습니다**<br />
          설치 직후 열려 있던 PowerShell에서는 인식이 안 될 수 있습니다. PowerShell 창을 닫고 새로 열거나, 컴퓨터를 재시작해 보세요.
        - **Docker Desktop이 "Engine starting" 에서 멈춰 있음**<br />
          [설치 전 확인 사항](#windows-설치-전-확인-사항)의 가상화가 켜져 있는지 확인하고, PowerShell(관리자)에서 `wsl --update` 를 실행한 뒤 재시작해 보세요.
        - **`error during connect` 또는 `Cannot connect to the Docker daemon` 오류**<br />
          Docker Desktop이 실행 중이 아닐 때 나오는 오류입니다. Docker Desktop을 실행하고 **Engine running** 표시가 뜰 때까지 기다린 후 다시 시도하세요.

        ## 설치 전 확인 사항
        Mac은 사용하는 **칩(프로세서) 종류**에 따라 내려받아야 하는 파일이 다릅니다. 먼저 내 Mac의 칩을 확인합니다.

        1. 화면 왼쪽 위의 **애플 로고**를 누릅니다.
        2. **이 Mac에 관하여** 를 누릅니다.
        3. 열린 창에서 아래 항목을 확인합니다.

        | 창에 표시되는 내용 | 내 Mac의 종류 | 내려받을 파일 |
        | --- | --- | --- |
        | **칩**: Apple M1, M2, M3, M4 ... | Apple 실리콘 Mac | **Docker Desktop for Mac with Apple silicon** |
        | **프로세서**: Intel Core i5, i7 ... | Intel Mac | **Docker Desktop for Mac with Intel chip** |

        <Callout type="info">
            같은 창에서 **macOS 버전**도 함께 확인하세요. Docker Desktop은 최신 macOS와 그 이전 두 개 버전까지만 지원합니다.<br />
            너무 오래된 macOS라면 `시스템 설정` → `일반` → `소프트웨어 업데이트` 에서 먼저 업데이트하는 것을 권장합니다. 메모리(RAM)는 4GB 이상이 필요합니다.
        </Callout>

        ## Mac에 Docker Desktop 설치하기
        <Steps>
            ### 설치 파일 내려받기
            [Docker Desktop 다운로드 페이지](https://docs.docker.com/desktop/setup/install/mac-install/)에 접속해
            위에서 확인한 칩 종류에 맞는 버튼을 눌러 `Docker.dmg` 파일을 내려받습니다.

            ### 응용 프로그램 폴더로 옮기기
            1. `다운로드` 폴더에서 내려받은 `Docker.dmg` 를 더블클릭해 엽니다.
            2. 창이 열리면 **고래 모양의 Docker 아이콘** 을 오른쪽의 **Applications(응용 프로그램) 폴더** 로 끌어다 놓습니다.
            3. 복사가 끝나면 창을 닫습니다.

            ### Docker Desktop 처음 실행하기
            1. `Command(⌘)` + `Space` 를 눌러 Spotlight 검색창을 열고 **Docker** 를 입력해 실행합니다.
            2. "인터넷에서 다운로드한 앱입니다. 여시겠습니까?" 라는 창이 뜨면 **열기** 를 누릅니다.
            3. 서비스 약관(Docker Subscription Service Agreement) 창이 뜨면 **Accept** 를 누릅니다.
            4. 설정 방식을 묻는 화면이 나오면 **Use recommended settings (권장 설정 사용)** 을 선택하고 `Finish` 를 누릅니다.
            5. Mac 로그인 비밀번호를 물어보면 입력합니다. (Docker가 필요한 도구를 설치하기 위해 필요합니다.)
            6. 로그인/회원가입 화면이 나오면 **Skip** 을 눌러 건너뛰어도 됩니다. (설문 화면도 `Skip` 으로 건너뛸 수 있습니다.)
            7. 화면 위쪽 메뉴 막대에 **고래 아이콘** 이 생기고, Docker Desktop 창 왼쪽 아래에 **Engine running** 이라는 초록색 표시가 나타나면 정상적으로 실행된 것입니다.

            <Callout type="warning">
                Docker 명령어를 사용할 때는 **항상 Docker Desktop이 실행 중이어야 합니다.** (메뉴 막대에 고래 아이콘이 있는지 확인하세요.)<br />
                Mac을 켤 때마다 자동으로 실행되게 하려면 Docker Desktop의 `Settings`(톱니바퀴) → `General` → **Start Docker Desktop when you sign in to your computer** 를 체크하세요.
            </Callout>

            ### 설치 확인하기
            `Command(⌘)` + `Space` 를 눌러 **터미널** (Terminal)을 검색해 실행한 뒤, 아래 명령어를 한 줄씩 입력합니다.
            ```bash
            docker --version
            docker compose version
            ```
            아래와 비슷하게 버전 정보가 나오면 설치가 잘 된 것입니다. (숫자는 달라도 괜찮습니다.)
            ```
            Docker version 28.x.x, build xxxxxxx
            Docker Compose version v2.x.x
            ```

            마지막으로 테스트용 프로그램을 실행해 봅니다.
            ```bash
            docker run hello-world
            ```
            몇 초 뒤 아래와 같은 내용이 뜬다면 성공적으로 설치가 된 것입니다.
            ```
            Hello from Docker!
            ...(생략)
            ```
        </Steps>

        ## 자주 발생하는 문제
        - **`zsh: command not found: docker`**<br />
          Docker Desktop을 한 번도 실행하지 않았거나, 설치 직후 열려 있던 터미널에서 실행한 경우입니다. Docker Desktop을 실행한 뒤 터미널을 완전히 종료(`Command(⌘)` + `Q`)하고 다시 열어 보세요.
        - **`Cannot connect to the Docker daemon` 오류**<br />
          Docker Desktop이 실행 중이 아닐 때 나오는 오류입니다. Docker Desktop을 실행하고 **Engine running** 표시가 뜰 때까지 기다린 후 다시 시도하세요.
        - **"손상되었기 때문에 열 수 없습니다" 또는 앱이 실행되지 않음**<br />
          칩 종류에 맞지 않는 파일을 받았을 수 있습니다. [설치 전 확인 사항](#설치-전-확인-사항-1)에서 칩 종류를 다시 확인하고, 응용 프로그램 폴더의 Docker를 휴지통으로 옮긴 뒤 올바른 파일로 다시 설치하세요.
