# 개발 환경 구성

직접 코드를 받아 개발을 위한 환경 구성을 설명합니다.

## 요구 사항

- [Node.js](https://nodejs.org) 24 이상
- [uv](https://docs.astral.sh/uv/) (Python 3.14는 uv가 알아서 설치합니다)
- Docker (MySQL·Redis를 띄우거나 전체를 컨테이너로 실행할 때)

## 저장소 준비하기

```bash
git clone https://github.com/scfs-miraepass/MIRAE-PASS.git
cd MIRAE-PASS

corepack enable
yarn install
```

## 실행하기

<Tabs items={['Docker', '직접 실행']}>
    <Tabs.Tab>

        소스 코드로 이미지를 빌드해 운영과 같은 구성으로 실행합니다.

        ```bash
        cp docker/example.env docker/.env # DB_ROOT_PASSWORD, DB_PASSWORD 채우기
        yarn run:docker
        ```

        [http://localhost:3000](http://localhost:3000)으로 접속합니다. <br />
        코드를 고친 뒤에는 이미지를 다시 빌드해야 하므로, 화면을 자주 고치는 작업에는 **직접 실행**이 편합니다.

    </Tabs.Tab>
    <Tabs.Tab>

        <Steps>

            ### MySQL과 Redis 실행하기

            이미 설치된 MySQL·Redis가 있다면 그것을 써도 됩니다. 없다면 Docker로 띄웁니다.

            ```bash
            docker run -d --name miraepass-mysql -p 3306:3306 \
              -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=miraepass \
              -e MYSQL_USER=miraepass -e MYSQL_PASSWORD=miraepass mysql
            docker run -d --name miraepass-redis -p 6379:6379 valkey/valkey
            ```

            ### 백엔드 실행하기

            ```bash
            cd server
            uv sync
            cp example.env .env
            ```

            `.env`를 채웁니다. 로컬에서는 HTTP로 접속하므로 `DEBUG=true`로 두어야 로그인 쿠키가 유지됩니다.

            ```dotenv filename="server/.env"
            DATABASE_URL=mysql+aiomysql://miraepass:miraepass@localhost:3306/miraepass
            REDIS_URL=redis://localhost:6379
            DEBUG=true
            ALLOWED_ORIGINS=*
            ```

            ```bash
            uv run alembic upgrade head
            uv run fastapi dev            # http://localhost:8000, API 문서는 /docs
            ```

            ### 테스트 사용자 만들기

            ```bash
            uv run python tools/create_test_users.py
            ```

            학생 `1101`~`1105`, 교사, 서비스 계정이 하나씩 만들어집니다. 처음 로그인할 때 비밀번호를 정합니다.

            ### 프론트엔드 실행하기

            저장소 루트에서 실행합니다.

            ```bash
            yarn dev:client     # Client 실행
            yarn dev:admin      # Admin 실행
            ```
            개발 환경에서 Client와 Admin 동시 실행은 불가능 합니다.

        </Steps>

    </Tabs.Tab>
</Tabs>
