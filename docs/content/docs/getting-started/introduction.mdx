# 소개
**미래패스(MIRAEPASS)** 는 순천미래과학고등학교에서 사용하는 교내 포인트 시스템입니다.

## 주요 특징

### 미래포인트
학교 구성원 모두가 이용할 수 있는 포인트 시스템입니다.<br />
교사가 학생에게 포인트를 지급하여 교내 카페, 노래방과 행사에서도 사용할 수 있습니다.
- **포인트 랭킹:** 주간, 누적으로 나뉘어서 포인트의 순위를 확인할 수 있습니다.
- **포인트 지급 및 차감(결제):** 권한이 있는 유저에 한해, 포인트 지급과 차감이 가능합니다.
- **포인트 한도:** 교사는 1주일에 최대 1,000P를 지급할 수 있고, 학생은 하루에 최대 1,000P를 받을 수 있습니다.
- **포인트 내역:** 교사 지급, 결제, 퀘스트, 스탬프, 노래방 입찰 등 모든 포인트 변동 내역이 사유와 함께 기록됩니다.

### 노래방 경매
보유하고 있는 '미래포인트'를 이용해 노래방 예약 경매에 참가할 수 있습니다.<br />
예약 경매에서 낙찰 시 노래방 이용 예약이 됩니다.
- **실시간 경매:** WebSocket 통신을 이용해 실시간 경매와 입찰이 가능합니다.
- **파티 경매:** 다른 사람과 포인트를 나누어 경매 입찰이 가능합니다.

### 스탬프
교내 행사의 부스 체험을 스탬프로 기록합니다.<br />
부스 운영자가 스탬프를 발급하면 '미래포인트'가 함께 지급됩니다.<br />
스탬프는 행사마다 상의할 수 있습니다.
- **스탬프 발급:** 권한이 있는 유저가 학생에게 부스별 스탬프를 발급할 수 있습니다.
- **중복 방지:** 같은 부스의 스탬프는 한 번만 받을 수 있습니다.
- **스탬프 보상:** 스탬프 1개당 50P가 지급됩니다.

### 관리자 대시보드
관리자는 별도의 대시보드에서 서비스 전체를 관리할 수 있습니다.
- **사용자 관리:** 사용자 생성, 정보 및 권한 수정, 삭제, 비밀번호 초기화가 가능합니다.
- **포인트 일괄 처리:** 여러 사용자에게 한 번에 포인트를 지급하거나 차감할 수 있습니다.



## 기술 스택

### 학생·교사용 웹 앱(`client`) / 관리자 대시보드(`admin`)
- **프레임워크:** [Nuxt](https://nuxt.com), TypeScript
- **UI:** [Nuxt UI](https://ui.nuxt.com), [TailwindCSS](https://tailwindcss.com)
- **PWA:** [Vite PWA](https://vite-pwa-org.netlify.app)를 이용해 앱처럼 설치하여 사용할 수 있습니다.
- **API 클라이언트:** [Hey API](https://heyapi.dev) (자세한 사용은 [API 문서](/api)를 참고하세요)
- **패키지 관리:** Yarn(Workspaces)

### Server
- **프레임워크:** [FastAPI](https://fastapi.tiangolo.com), Python 3.14
- **ORM 및 마이그레이션:** [SQLModel](https://sqlmodel.tiangolo.com), [SQLAlchemy](https://www.sqlalchemy.org)(비동기), [Alembic](https://alembic.sqlalchemy.org)
- **인증:** 세션 기반 로그인이며, 비밀번호는 Argon2로 해싱합니다.
- **스케줄러:** [APScheduler](https://apscheduler.readthedocs.io)로 주기적인 작업을 처리합니다.
- **패키지 관리:** [uv](https://docs.astral.sh/uv/)

#### Database
- **MySQL:** 사용자, 포인트, 노래방 경매 등 데이터를 저장합니다.
- **Valkey(Redis 호환):** 로그인 세션, 캐시, 노래방 경매 실시간 메시지를 처리합니다.

### 인프라 및 개발 도구
- **배포:** Docker Compose로 모든 서비스를 실행하며, 이미지는 GitHub Container Registry(GHCR)에 배포됩니다.
- **코드 검사:** [pre-commit](https://pre-commit.com)으로 커밋 전에 Ruff(백엔드)와 타입 검사(프론트엔드)를 실행합니다.
- **릴리즈:** [semantic-release](https://semantic-release.gitbook.io)와 GitHub Actions로 버전 관리와 릴리즈를 자동화합니다.
- **문서:** 이 문서는 [Nextra](https://nextra.site)(Next.js)로 작성되었습니다.
