# 소개
**미래패스(MIRAEPASS)** 는 순천미래과학고등학교에서 사용하는 교내 포인트 시스템입니다.

## 주요 특징

### 미래포인트
학교 구성원 모두가 이용할 수 있는 포인트 시스템입니다.<br />
교사가 학생에게 포인트를 지급하여 교내 카페, 노래방과 행사에서도 사용할 수 있습니다.
- **포인트 랭킹:** 주간, 누적으로 나뉘어서 포인트의 순위를 확인할 수 있습니다.
- **포인트 지급 및 차감(결제):** 권한이 있는 유저에 한해, 포인트 지급과 차감이 가능합니다.
- **포인트 한도:** 교사는 1주일에 최대 1,000P를 지급할 수 있고, 학생은 하루에 최대 1,000P를 받을 수 있습니다.
- **포인트 내역:** 교사 지급, 결제, 퀘스트, 스탬프, 노래방 입찰 등 모든 포인트 변동 내역이 사유와 함께 기록됩니다.

### 노래방 경매
보유하고 있는 '미래포인트'를 이용해 노래방 예약 경매에 참가할 수 있습니다.<br />
예약 경매에서 낙찰 시 노래방 이용 예약이 됩니다.
- **실시간 경매:** WebSocket 통신을 이용해 실시간 경매와 입찰이 가능합니다.
- **파티 경매:** 다른 사람과 포인트를 나누어 경매 입찰이 가능합니다.

### 스탬프
교내 행사의 부스 체험을 스탬프로 기록합니다.<br />
부스 운영자가 스탬프를 발급하면 '미래포인트'가 함께 지급됩니다.<br />
스탬프는 행사마다 상의할 수 있습니다.
- **스탬프 발급:** 권한이 있는 유저가 학생에게 부스별 스탬프를 발급할 수 있습니다.
- **중복 방지:** 같은 부스의 스탬프는 한 번만 받을 수 있습니다.
- **스탬프 보상:** 스탬프 1개당 50P가 지급됩니다.

### 관리자 대시보드
관리자는 별도의 대시보드에서 서비스 전체를 관리할 수 있습니다.
- **사용자 관리:** 사용자 생성, 정보 및 권한 수정, 삭제, 비밀번호 초기화가 가능합니다.
- **포인트 일괄 처리:** 여러 사용자에게 한 번에 포인트를 지급하거나 차감할 수 있습니다.



## 구성 요소
미래패스는 다섯 개의 [컨테이너](/docs/concept/docker#Container)로 동작합니다.

| 서비스     | 컨테이너           | 역할                                                         |
|------------|--------------------|--------------------------------------------------------------|
| `client`   | `miraepass_client` | 학생·교사가 사용하는 웹 앱(PWA). 유일하게 외부로 공개됩니다. |
| `admin`    | `miraepass_admin`  | 관리자 대시보드. `/admin` 경로로 제공됩니다.                 |
| `server`   | `miraepass_server` | 백엔드 API                                                   |
| `database` | `miraepass_mysql`  | 사용자, 포인트, 노래방 경매 등 데이터 저장                   |
| `redis`    | `miraepass_redis`  | 로그인 세션, 캐시, 노래방 경매 실시간 메시지                 |
