# 소개
**미래패스(MIRAEPASS)** 는 순천미래과학고등학교에서 사용하는 교내 포인트 시스템입니다.

## 구성 요소
미래패스는 다섯 개의 [컨테이너](/docs/concept/docker#Container)로 동작합니다.

| 서비스 | 컨테이너 | 역할 | 기술 |
| --- | --- | --- | --- |
| `client` | `miraepass_client` | 학생·교사가 사용하는 웹 앱(PWA). 외부에 공개되는 유일한 진입점입니다. | Nuxt 4 |
| `admin` | `miraepass_admin` | 관리자 대시보드. `/admin` 경로로 제공됩니다. | Nuxt 4 |
| `server` | `miraepass_server` | 백엔드 API | FastAPI, SQLAlchemy |
| `database` | `miraepass_mysql` | 사용자, 포인트, 노래방 경매 등 데이터 저장 | MySQL |
| `redis` | `miraepass_redis` | 로그인 세션, 캐시, 노래방 경매 실시간 메시지 | Valkey(Redis 호환) |

## 요청 흐름

외부에서는 `client`의 `3000` 포트만 접근할 수 있습니다. `client`가 경로에 따라 요청을 내부 서비스로 넘겨줍니다.

```
브라우저 ──▶ client:3000
              ├─ /           → client 페이지
              ├─ /admin/**   → admin:5234
              └─ /api/**     → server:8000  (/api 접두사는 떼고 전달)
                                 ├─ database:3306
                                 └─ redis:6379
```

노래방 경매의 실시간 통신(`/api/karaoke/{id}/ws`)도 WebSocket으로 같은 경로를 거쳐 `server`에 연결됩니다.
