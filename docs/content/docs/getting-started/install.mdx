# 설치

## 요구 사항

- Docker Engine과 Docker Compose v2 (설치 방법은 [Docker 설치 가이드](/docs/install-docker)를 확인하세요)
- 외부에서 접속할 도메인 및 HTTPS 인증서 (자세한 사항은 [프록시 구성](/docs/getting-started/config#리버스-프록시)을 참고하세요)

## 설치하기

<Steps>

    ### 프로젝트 폴더 만들기

    `docker-compose.yml`과 `.env`를 둘 폴더를 만듭니다. 데이터와 로그도 이 폴더 아래에 생깁니다.

    ```bash
    mkdir miraepass && cd miraepass
    ```

    ### 설정 파일 받기

    저장소의 `docker` 폴더에서 Compose 파일과 환경 변수 예제를 받습니다.

    ```bash
    curl -fsSLo docker-compose.yml https://raw.githubusercontent.com/scfs-miraepass/MIRAE-PASS/master/docker/docker-compose.yml
    curl -fsSLo .env https://raw.githubusercontent.com/scfs-miraepass/MIRAE-PASS/master/docker/example.env
    ```

    ### 환경 변수 작성하기

    `.env`를 열어 데이터베이스 비밀번호를 채웁니다. 두 값은 비워 둘 수 없습니다.

    ```dotenv filename=".env"
    DB_ROOT_PASSWORD=루트_비밀번호
    DB_PASSWORD=서비스_비밀번호
    DB_USERNAME=miraepass
    DB_DATABASE_NAME=miraepass
    ```
    <Callout type="info">
        ```
        openssl rand -base64 24
        ```
        명령어를 사용해 비밀번호를 생성할 수 있습니다.
    </Callout>

    <Callout type="warning">
    `DB_ROOT_PASSWORD`와 `DB_PASSWORD`는 MySQL이 **처음 실행될 때만** 적용됩니다.<br />
    `data/` 폴더가 만들어진 뒤에 비밀번호를 바꾸려면 MySQL 안에서 직접 바꿔야 합니다.
    </Callout>
    자세한 설정을 원한다면 [환경 변수](/docs/getting-started/environment)를 참고하세요.

    ### 실행하기

    ```bash
    docker compose up -d
    ```

    자동으로 [이미지](/docs/concept/docker#image)가 설치되고 실행이 진행됩니다.
    실행후 10~15초 후, [http://localhost:3000](http://localhost:3000)를 통해 접속할 수 있습니다.
    <Callout type="info">
        기본적으로 서버는 3000포트로 실행되며, 외부 접근이 허용되어 있습니다.<br />
        원격의 서버에서 실행하는 경우, localhost를 서버의 IP를 사용해야 합니다.
    </Callout>
    <Callout type="warning">
        운영 모드(`DEBUG=false`)에서는 **HTTPS에서만 로그인이 유지됩니다.**
        `http://서버주소:3000`으로는 화면만 확인하고, 실제 로그인은 [리버스 프록시](/docs/getting-started/config#리버스-프록시)로 HTTPS를 붙인 뒤에 하세요.
    </Callout>
</Steps>

## 생성되는 파일

<FileTree>
    <FileTree.Folder name="miraepass" defaultOpen>
        <FileTree.File name="docker-compose.yml" />
        <FileTree.File name=".env" />
        <FileTree.Folder name="data" open={false} />
        <FileTree.Folder name="logs" open={false} />
    </FileTree.Folder>
</FileTree>
- **data:** 데이터가 저장되는 폴더입니다. **이 폴더를 지우면 모든 사용자와 포인트 기록 등 데이터가 사라집니다.**
- **logs:** 서비스의 로그가 저장되는 폴더입니다. 네트워크 부터 서비스의 로그를 확인할 수 있습니다.
