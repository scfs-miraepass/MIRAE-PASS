# Git 설치 가이드

이 문서에서는 운영체제별로 Git을 설치하고, 처음 한 번 해야 하는 설정 방법을 설명합니다.<br />
Git이 무엇인지 모른다면 먼저 [Git 이해하기](/docs/concept/git)를 읽어 보세요.

<Tabs items={['Linux', 'Windows', 'MacOS']}>
    <Tabs.Tab>
        <Callout type="warning">
            이 문서에서는 Debian 계열(Debian, Ubuntu 등)의 Linux에서 설치하는 방법을 설명합니다.<br />
            다른 계열의 Linux의 경우 [Git 공식 문서](https://git-scm.com/downloads/linux)를 참고바랍니다.
        </Callout>

        ## Linux에 Git 설치하기
        <Steps>
            ### Git 설치
            터미널을 열고 아래 명령어를 실행합니다. 비밀번호를 물어보면 내 계정의 비밀번호를 입력합니다. (입력해도 화면에 표시되지 않는 것이 정상입니다.)
            ```bash
            sudo apt update
            sudo apt install git
            ```

            ### 설치 확인하기
            ```bash
            git --version
            ```
            아래와 비슷하게 버전 정보가 나오면 설치가 잘 된 것입니다. (숫자는 달라도 괜찮습니다.)
            ```
            git version 2.x.x
            ```

            ### 이름과 이메일 설정하기
            [아래의 처음 설정하기](#처음-설정하기)를 따라 이름과 이메일을 설정합니다.
        </Steps>
    </Tabs.Tab>
    <Tabs.Tab>
        <Callout type="info">
            Windows에서는 **Git for Windows**라는 프로그램을 설치합니다.<br />
            일반 프로그램을 설치하는 것처럼 설치 파일을 내려받아 실행하면 됩니다.
        </Callout>

        ## Windows에 Git 설치하기
        <Steps>
            ### 설치 파일 내려받기
            [Git for Windows 다운로드 페이지](https://git-scm.com/downloads/win)에 접속해
            **Click here to download** 링크를 눌러 설치 파일(`Git-2.x.x-64-bit.exe`)을 내려받습니다.

            <Callout type="info">
                대부분의 Windows 노트북·데스크톱은 기본으로 내려받아지는 **64-bit** 파일을 사용하면 됩니다.<br />
                Surface Pro X, 갤럭시 북 엣지 같은 Snapdragon(ARM) 노트북을 사용하는 경우에만 **ARM64** 버전을 받습니다.
            </Callout>

            ### 설치 프로그램 실행하기
            1. 내려받은 설치 파일을 더블클릭해 실행합니다.
            2. "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 라는 창이 뜨면 **예** 를 누릅니다.
            3. 설치 과정에서 여러 개의 설정 화면이 나옵니다. **아래 한 화면을 제외하고는 바꾸지 않고 `Next` 를 누르면 됩니다.**

            | 화면 제목 | 선택할 항목 |
            | --- | --- |
            | **Choosing the default editor used by Git** | 목록을 눌러 **Use Notepad as Git's default editor** (메모장) 또는 사용 중인 편집기(예: Visual Studio Code)를 선택합니다. |

            4. 마지막 화면에서 `Install` 을 누르면 설치가 진행됩니다.
            5. 설치가 끝나면 `Finish` 를 누릅니다.

            <Callout type="info">
                기본 편집기를 바꾸지 않으면 **Vim**이라는 편집기가 선택됩니다. Vim은 사용법이 독특해서 처음 쓰는 사람은 창을 닫는 방법도 찾기 어렵습니다.<br />
                Git이 메시지를 입력하라고 편집기를 열었을 때 당황하지 않도록 익숙한 편집기를 고르는 것을 권장합니다.
            </Callout>

            ### 설치 확인하기
            `Win` 키를 누르고 **PowerShell** 을 검색해 실행(관리자 권한 필요 없음)한 뒤, 아래 명령어를 입력합니다.
            ```powershell
            git --version
            ```
            아래와 비슷하게 버전 정보가 나오면 설치가 잘 된 것입니다. (숫자는 달라도 괜찮습니다.)
            ```
            git version 2.x.x.windows.1
            ```

            ### 이름과 이메일 설정하기
            [아래의 처음 설정하기](#처음-설정하기)를 따라 이름과 이메일을 설정합니다.
        </Steps>

        ## Windows에서 자주 발생하는 문제
        - **`git` 은(는) 내부 또는 외부 명령... 이 아닙니다** / **`git` 용어가 cmdlet... 으로 인식되지 않습니다**<br />
          설치 전에 열려 있던 PowerShell에서는 인식이 안 될 수 있습니다. PowerShell 창을 닫고 새로 열거나, 컴퓨터를 재시작해 보세요.
        - **`git commit` 을 했더니 이상한 화면이 열리고 나갈 수 없음**<br />
          기본 편집기로 Vim이 선택된 경우입니다. `Esc` 를 누른 뒤 `:q!` 를 입력하고 `Enter` 를 누르면 커밋을 취소하고 빠져나옵니다.
          커밋할 때 `git commit -m "메시지"` 처럼 `-m` 으로 메시지를 함께 적으면 편집기가 열리지 않습니다.
    </Tabs.Tab>
    <Tabs.Tab>
        <Callout type="info">
            macOS에서는 Apple이 제공하는 **Command Line Tools**(명령어 개발 도구)를 설치하면 Git이 함께 설치됩니다.<br />
            이미 Xcode나 Command Line Tools를 설치했다면 Git도 이미 설치되어 있습니다.
        </Callout>

        ## Mac에 Git 설치하기
        <Steps>
            ### 터미널 열기
            `Command(⌘)` + `Space` 를 눌러 Spotlight 검색창을 열고 **터미널** (Terminal)을 검색해 실행합니다.

            ### 설치 명령어 실행하기
            터미널에 아래 명령어를 입력하고 `Enter` 를 누릅니다.
            ```bash
            xcode-select --install
            ```

            - **"명령어 개발 도구를 지금 설치하시겠습니까?"** 라는 창이 뜨면 **설치** 를 누르고, 사용권 계약에 **동의** 합니다. 몇 분 정도 걸릴 수 있습니다.
            - 터미널에 **`command line tools are already installed`** 라는 메시지가 나오면 이미 설치되어 있는 것입니다. 다음 단계로 넘어가세요.

            ### 설치 확인하기
            설치가 끝나면 터미널에 아래 명령어를 입력합니다.
            ```bash
            git --version
            ```
            아래와 비슷하게 버전 정보가 나오면 설치가 잘 된 것입니다. (숫자는 달라도 괜찮습니다.)
            ```
            git version 2.x.x (Apple Git-xxx)
            ```

            ### 이름과 이메일 설정하기
            [아래의 처음 설정하기](#처음-설정하기)를 따라 이름과 이메일을 설정합니다.
        </Steps>

        <Callout type="info">
            [Homebrew](https://brew.sh)를 사용하고 있다면 `brew install git` 으로 더 최신 버전의 Git을 설치할 수도 있습니다. 미래패스 개발에는 어느 쪽을 사용해도 괜찮습니다.
        </Callout>

        ## Mac에서 자주 발생하는 문제
        - **`xcrun: error: invalid active developer path` 오류**<br />
          macOS를 업데이트한 뒤 자주 생기는 문제입니다. 터미널에서 `xcode-select --install` 을 다시 실행해 Command Line Tools를 다시 설치하세요.
        - **`git commit` 을 했더니 이상한 화면이 열리고 나갈 수 없음**<br />
          Vim이라는 편집기가 열린 것입니다. `Esc` 를 누른 뒤 `:q!` 를 입력하고 `Enter` 를 누르면 커밋을 취소하고 빠져나옵니다.
          커밋할 때 `git commit -m "메시지"` 처럼 `-m` 으로 메시지를 함께 적으면 편집기가 열리지 않습니다.
    </Tabs.Tab>
</Tabs>

## 처음 설정하기

Git은 [커밋](/docs/concept/git#commit)할 때마다 **누가 했는지**를 함께 기록합니다. 그래서 설치 후 처음 한 번은 내 이름과 이메일을 알려 주어야 합니다.<br />
운영체제와 관계없이 터미널(Windows는 PowerShell)에서 아래 명령어를 실행합니다. `"` 안의 내용을 내 정보로 바꿔서 입력하세요.

```bash
git config --global user.name "홍길동"
git config --global user.email "gildong@example.com"
```

잘 설정되었는지 확인합니다.

```bash
git config --global --list
```

```
user.name=홍길동
user.email=gildong@example.com
```

<Callout type="info">
    이메일은 **GitHub 계정에 등록한 이메일**과 같게 설정하는 것을 권장합니다. 그래야 GitHub에서 내 커밋이 내 계정과 연결되어 표시됩니다.<br />
    이메일을 공개하고 싶지 않다면 GitHub의 `Settings` → `Emails` 에서 **Keep my email addresses private** 를 켜고, 그 아래에 표시되는 `...@users.noreply.github.com` 주소를 대신 사용할 수 있습니다.
</Callout>

<Callout type="warning">
    여기에 설정한 이름과 이메일은 커밋 기록에 남고, GitHub에 push하면 **누구나 볼 수 있습니다.** 공개되어도 괜찮은 정보로 설정하세요.
</Callout>

설정을 마쳤다면 [개발 환경 구성](/docs/development/develop)으로 돌아가 저장소를 준비합니다.
