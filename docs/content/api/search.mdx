# 유저 검색

이름이나 학번으로 유저를 찾는 API입니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `GET` | `/search` | [유저 검색](#유저-검색) | `SEARCH_USER` |
| `GET` | `/search/teacher/{user_name}` | [교사 정보 조회](#교사-정보-조회) | 없음 |

## 유저 검색

`GET /search` · SDK `searchSearchGet`

검색어로 유저를 찾습니다. 포인트 지급, 스탬프 발급, 노래방 파티 초대처럼 **대상을 고를 때** 사용합니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `q` | 문자 | ○ | 검색어 (이름 또는 학번) |
| 쿼리 | `t` | 유저 종류 목록 | | 찾을 유저 종류를 제한합니다. 예: `["student", "teacher"]` |

검색어에 따라 찾는 방식이 달라집니다.

| 검색어 | 찾는 방식 | 예시 |
| --- | --- | --- |
| **숫자 4자리 이상** | ID(학번)가 **정확히 같은** 유저를 찾습니다. | `1101` → 1101번 학생 |
| 숫자 3자리 이하 | 결과가 항상 비어 있습니다. | `110` → 결과 없음 |
| **글자가 포함됨** | 이름의 **일부**가 맞는 유저를 모두 찾습니다. | `길동`, `홍길` → 홍길동 |
| **초성** | 이름의 초성이 맞는 유저를 찾습니다. | `ㅎㄱㄷ` → 홍길동 |

<Callout type="info">
    이름 검색은 한글을 **자음과 모음으로 나누어** 비교합니다. 그래서 `홍기`처럼 글자를 다 입력하지 않은 상태에서도 `홍길동`이 검색됩니다.
    입력하는 도중에도 결과를 보여줄 수 있어 자동 완성에 적합합니다.
</Callout>

**응답** `200` — 찾은 유저 목록을 돌려줍니다. 각 항목은 [유저 정보](/api/auth#로그인)와 같은 모양입니다.

```json
{
    "success": true,
    "data": [
        { "id": 1101, "type": "student", "name": "홍길동", "grade": 1, "number": 1, "point": 120, "...": "..." }
    ]
}
```

| 오류 | 이유 |
| --- | --- |
| `401` | 로그인하지 않았습니다. |
| `403` | `SEARCH_USER` 권한이 없습니다. |

```ts
const req = await $API.searchSearchGet({
    query: { q: "홍길", t: ["student"] },
})
const users = req.data?.data ?? []
```

## 교사 정보 조회

`GET /search/teacher/{user_name}` · SDK `teacherGetByNameSearchTeacherUserNameGet`

교사의 **정확한 이름**으로 교사 정보를 가져옵니다. 로그인하지 않아도 사용할 수 있습니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 경로 | `user_name` | 문자 | ○ | 교사의 이름 (일부만 입력하면 찾지 못합니다) |

| 오류 | 이유 |
| --- | --- |
| `404` | 해당 이름의 교사가 없습니다. |

```ts
await $API.teacherGetByNameSearchTeacherUserNameGet({ path: { user_name: "김교사" } })
```
