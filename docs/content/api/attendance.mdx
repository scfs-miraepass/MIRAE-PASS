# 출석체크

<Callout type="warning">
    해당 기능은 개발이 완료되지 않은 기능입니다. 이에 따라 API가 변경될 수 있습니다.
</Callout>

**출석체크**는 학생 · 교사가 평일에 하루 한 번 출석하고 포인트를 받는 기능입니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `GET` | `/attendance` | [출석체크 상태 조회](#출석체크-상태-조회) | `CHECK_ATTENDANCE` |
| `POST` | `/attendance` | [출석체크](#출석하기) | `CHECK_ATTENDANCE` |

## 규칙

| 항목 | 내용 |
| --- | --- |
| 출석할 수 있는 날 | 월~금 중 휴업일 · 공휴일이 아닌 날(수업일)에 **하루 한 번** 출석할 수 있습니다. 날짜는 한국 시간(KST) 기준입니다. |
| 기본 보상 | 출석하면 **10포인트**를 받습니다. (기록 종류 `attendance`) |
| 연속 출석 | 마지막 출석일과 오늘 사이에 **수업일이 하루도 없으면** 연속으로 봅니다. 금요일 다음 월요일, 공휴일 · 방학을 건너뛴 출석도 연속입니다. |
| 보너스 | 연속 출석 일수가 **11의 배수**(11일, 22일, ...)인 날은 10포인트 대신 **100포인트**를 받습니다. (기록 종류 `attendance_bonus`) 보너스를 받아도 연속 일수는 계속 이어집니다. |

휴업일 · 공휴일은 [NEIS 학사일정](https://open.neis.go.kr)에서 수업공제일명이 `휴업일` 또는 `공휴일`인 날입니다. 학사일정은 달마다 6시간 동안 캐시합니다.

<Callout type="info">
    학사일정을 확인할 수 없으면(NEIS 설정이 없거나 요청이 실패한 경우) 공휴일에 포인트가 지급되지 않도록 출석을 막고 `503`으로 응답합니다.
    NEIS 설정 방법은 [환경 변수](/docs/getting-started/environment)를 참고합니다.
</Callout>

## 출석체크 상태 조회

`GET /attendance` · SDK `getAttendanceAttendanceGet`

오늘 출석할 수 있는지, 이미 출석했는지, 현재 연속 출석 일수를 가져옵니다.

```json
{
    "success": true,
    "data": {
        "today": "2026-11-27",
        "available": true,
        "attended": false,
        "streak": 10,
        "days_to_bonus": 1,
        "reward": 100
    }
}
```

| 항목 | 설명 |
| --- | --- |
| `today` | 오늘 날짜 (KST) |
| `available` | 오늘이 출석할 수 있는 날인지입니다. 주말 · 휴업일 · 공휴일이면 `false`입니다. |
| `attended` | 오늘 이미 출석했는지입니다. |
| `streak` | 현재 연속 출석 일수입니다. 오늘 출석했다면 오늘을 포함하고, 연속이 끊겼다면 `0`입니다. |
| `days_to_bonus` | 다음 보너스까지 남은 출석 횟수입니다. `1`이면 다음 출석에서 보너스를 받습니다. |
| `reward` | 다음 출석에서 받을 포인트입니다. |

| 오류 | 이유 |
| --- | --- |
| `403` | `CHECK_ATTENDANCE` 권한이 없습니다. |
| `503` | 학사일정을 확인할 수 없습니다. |

```ts
const req = await $API.getAttendanceAttendanceGet()
```

## 출석하기

`POST /attendance` · SDK `checkAttendanceAttendancePost`

오늘 출석하고 포인트를 받습니다.

**응답** `201`

```json
{
    "success": true,
    "data": {
        "attend_date": "2026-11-27",
        "streak": 11,
        "reward": 100,
        "bonus": true,
        "point": 1250
    }
}
```

| 항목 | 설명 |
| --- | --- |
| `attend_date` | 출석일 (KST) |
| `streak` | 이번 출석까지의 연속 출석 일수 |
| `reward` | 받은 포인트 |
| `bonus` | 연속 출석 보너스인지 |
| `point` | 포인트를 받은 뒤의 **보유 포인트** |

| 오류 | 이유 |
| --- | --- |
| `400` | 오늘은 출석할 수 없는 날(주말 · 휴업일 · 공휴일)입니다. |
| `403` | `CHECK_ATTENDANCE` 권한이 없습니다. |
| `409` | 오늘 이미 출석했습니다. |
| `503` | 학사일정을 확인할 수 없습니다. |

```ts
const req = await $API.checkAttendanceAttendancePost()
if (req.data) {
    console.log(`${req.data.data.streak}일 연속 출석! +${req.data.data.reward}P`)
}
```
