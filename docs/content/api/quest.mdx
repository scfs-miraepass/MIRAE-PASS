# 퀘스트

<Callout type="warning">
    해당 기능은 개발이 완료되지 않은 기능입니다. 이에 따라 API가 변경될 수 있습니다.
</Callout>

**퀘스트**는 교사가 낸 과제이며, 학생이 완료하면 보상 포인트를 받습니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `GET` | `/quest` | [퀘스트 목록](#퀘스트-목록) | `VIEW_QUEST` |
| `GET` | `/quest/{quest_id}` | [퀘스트 조회](#퀘스트-조회) | `VIEW_QUEST` |
| `POST` | `/quest/create` | [퀘스트 생성](#퀘스트-생성) | `CREATE_QUEST` |
| `PUT` | `/quest/{quest_id}` | [퀘스트 수정](#퀘스트-수정) | 만든 사람 또는 `MANAGE_QUEST` |
| `DELETE` | `/quest/{quest_id}` | [퀘스트 삭제](#퀘스트-삭제) | 만든 사람 또는 `MANAGE_QUEST` |
| `POST` | `/quest/{quest_id}/complete` | [퀘스트 완료](#퀘스트-완료) | `JOIN_QUEST` |

## 퀘스트 정보

```json
{
    "id": 3,
    "title": "도서관 책 정리 돕기",
    "description": "점심시간에 도서관 반납 도서를 정리합니다.",
    "reward": 30,
    "end_date": "2026-11-30T23:59:00+09:00",
    "max_repeat": 2,
    "created_at": "2026-11-01T09:00:00+09:00",
    "author_id": 4001
}
```

| 항목 | 설명 |
| --- | --- |
| `reward` | 완료하면 받는 포인트입니다. **최대 300점**입니다. |
| `end_date` | 마감 시간입니다. 이 시간이 지나면 완료할 수 없습니다. |
| `max_repeat` | 한 학생이 **몇 번까지** 완료할 수 있는지입니다. (1 이상) |
| `author_id` | 퀘스트를 만든 사람의 ID입니다. |

## 퀘스트 목록

`GET /quest` · SDK `listQuestsQuestGet`

모든 퀘스트를 **마감이 빠른 순서**로 가져옵니다. 응답 헤더 `X-MAX-PAGE`에 전체 페이지 수가 들어 있습니다.

| 위치 | 이름 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `limit` | 숫자 | 20 | 가져올 개수 (1~100) |
| 쿼리 | `offset` | 숫자 | 0 | 건너뛸 개수 |

```ts
const req = await $API.listQuestsQuestGet({ query: { limit: 20, offset: 0 } })
```

## 퀘스트 조회

`GET /quest/{quest_id}` · SDK `getQuestQuestQuestIdGet`

퀘스트 하나의 정보를 가져옵니다. 없으면 `404`로 응답합니다.

## 퀘스트 생성

`POST /quest/create` · SDK `createQuestQuestCreatePost`

새로운 퀘스트를 만듭니다. 교사 또는 관리자만 만들 수 있습니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `title` | 문자 | ○ | 제목 |
| 본문 | `description` | 문자 | ○ | 내용 |
| 본문 | `reward` | 숫자 | ○ | 보상 포인트 (1~300) |
| 본문 | `end_date` | 날짜·시간 | ○ | 마감 시간 |
| 본문 | `max_repeat` | 숫자 | ○ | 한 학생당 최대 완료 횟수 (1 이상) |

**응답** `201` — 만들어진 [퀘스트 정보](#퀘스트-정보)를 돌려줍니다.

| 오류 | 이유 |
| --- | --- |
| `403` | `CREATE_QUEST` 권한이 없습니다. |
| `429` | 보상이 300점을 넘습니다. |

```ts
await $API.createQuestQuestCreatePost({
    body: {
        title: "도서관 책 정리 돕기",
        description: "점심시간에 도서관 반납 도서를 정리합니다.",
        reward: 30,
        end_date: "2026-11-30T23:59:00+09:00",
        max_repeat: 2,
    },
})
```

## 퀘스트 수정

`PUT /quest/{quest_id}` · SDK `updateQuestQuestQuestIdPut`

퀘스트를 수정합니다. [퀘스트 생성](#퀘스트-생성)과 같은 값을 보내며, **바꾸고 싶은 값만** 보내도 됩니다.
퀘스트를 만든 사람이나 `MANAGE_QUEST` 권한이 있는 사람만 수정할 수 있습니다.

| 오류 | 이유 |
| --- | --- |
| `403` | 수정할 권한이 없습니다. |
| `404` | 퀘스트가 없습니다. |
| `429` | 보상이 300점을 넘습니다. |

```ts
await $API.updateQuestQuestQuestIdPut({
    path: { quest_id: 3 },
    body: { reward: 50 },
})
```

## 퀘스트 삭제

`DELETE /quest/{quest_id}` · SDK `deleteQuestQuestQuestIdDelete`

퀘스트를 삭제합니다. 퀘스트를 만든 사람이나 `MANAGE_QUEST` 권한이 있는 사람만 삭제할 수 있습니다.

**응답** `204` — 본문이 없습니다.

## 퀘스트 완료

`POST /quest/{quest_id}/complete` · SDK `completeQuestQuestQuestIdCompletePost`

로그인한 학생이 퀘스트를 완료하고 보상 포인트를 받습니다.

**응답** `200` — 보상을 받은 뒤의 **보유 포인트**를 돌려줍니다.

```json
{ "success": true, "data": 150 }
```

| 오류 | 이유 |
| --- | --- |
| `400` | 마감 시간이 지났습니다. |
| `403` | 퀘스트에 참여할 권한이 없습니다. |
| `404` | 퀘스트가 없습니다. |
| `429` | 최대 완료 횟수(`max_repeat`)를 모두 사용했습니다. |

```ts
const req = await $API.completeQuestQuestQuestIdCompletePost({ path: { quest_id: 3 } })
if (req.data) {
    console.log(`보상을 받았습니다! 현재 포인트: ${req.data.data}`)
}
```
