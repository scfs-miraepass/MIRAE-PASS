# 게시글

<Callout type="warning">
    해당 기능은 개발이 완료되지 않은 기능입니다. 이에 따라 API가 변경될 수 있습니다.
</Callout>

공지사항 같은 게시글을 다루는 API입니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `GET` | `/posts` | [게시글 목록](#게시글-목록) | `VIEW_POST` (공지 목록은 `CREATE_POST` 또는 `MANAGE_POST`로도 조회 가능) |
| `GET` | `/posts/{post_id}` | [게시글 조회](#게시글-조회) | `VIEW_POST` |
| `POST` | `/posts` | [게시글 작성](#게시글-작성) | `CREATE_POST` |
| `PATCH` | `/posts/{post_id}` | [게시글 수정](#게시글-수정) | 작성자 또는 `MANAGE_POST` |
| `DELETE` | `/posts/{post_id}` | [게시글 삭제](#게시글-삭제) | 작성자 또는 `MANAGE_POST` |
| `GET` | `/posts/{post_id}/poll` | [설문 조회](#설문-조회) | `VIEW_POST` (작성자·`MANAGE_POST`는 결과 포함) |
| `PUT` | `/posts/{post_id}/poll` | [설문 저장](#설문-저장) | 작성자 또는 `MANAGE_POST` |
| `DELETE` | `/posts/{post_id}/poll` | [설문 삭제](#설문-삭제) | 작성자 또는 `MANAGE_POST` |
| `PUT` | `/posts/{post_id}/poll/vote` | [설문 응답](#설문-응답) | `VIEW_POST` |
| `DELETE` | `/posts/{post_id}/poll/vote` | [설문 응답 취소](#설문-응답-취소) | `VIEW_POST` |

## 게시글 정보

```json
{
    "id": 12,
    "title": "11월 포인트 이벤트 안내",
    "views": 0,
    "created_at": "2026-11-01T09:00:00+09:00",
    "updated_at": "2026-11-02T10:30:00+09:00",
    "author_id": 4001,
    "has_poll": true
}
```

| 항목 | 설명 |
| --- | --- |
| `views` | 조회수입니다. |
| `created_at` | 작성한 시간입니다. |
| `updated_at` | 마지막으로 수정한 시간입니다. |
| `author_id` | 작성자의 ID입니다. |
| `has_poll` | [설문](#설문)이 연결되어 있는지 여부입니다. |

상세 조회와 본문 유형을 지정한 목록 조회는 `content_data`를 반환합니다. 유형을 지정하지 않은 목록에서는 본문 값이 `null`입니다.

## 게시글 목록

`GET /posts` · SDK `getPostsPostsGet`

게시글을 **최신순**으로 가져옵니다. 응답 헤더 `X-MAX-PAGE`에 전체 페이지 수가 들어 있습니다.

| 위치 | 이름 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `page` | 숫자 | 1 | 페이지 번호 (1부터 시작) |
| 쿼리 | `size` | 숫자 | 20 | 한 페이지의 게시글 수 (1~100) |
| 쿼리 | `content_kind` | 문자 | 없음 | 본문의 `kind` 값으로 필터링합니다. 공지사항은 `notice`를 사용합니다. |

```ts
const req = await $API.getPostsPostsGet({ query: { page: 1, size: 10 } })
const posts = req.data?.data ?? []
const maxPage = Number(req.response?.headers.get("X-MAX-PAGE"))
```

## 게시글 조회

`GET /posts/{post_id}` · SDK `getPostPostsPostIdGet`

게시글 하나의 정보를 가져옵니다. 없으면 `404`로 응답합니다.

```ts
await $API.getPostPostsPostIdGet({ path: { post_id: 12 } })
```

## 게시글 작성

`POST /posts` · SDK `createPostPostsPost`

새 게시글을 작성합니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `title` | 문자 | ○ | 제목 |
| 본문 | `content_data` | 객체(JSON) | ○ | 본문 내용입니다. 글자뿐 아니라 굵게, 이미지 같은 꾸밈 정보도 담을 수 있도록 JSON 객체로 저장합니다. |
| 본문 | `poll` | [설문 내용](#설문-내용) | | 함께 만들 설문입니다. 게시글과 같은 트랜잭션에서 만들어, 설문이 빠진 게시글이 남지 않습니다. |

**응답** `201` — 작성된 [게시글 정보](#게시글-정보)를 돌려줍니다.

| 오류 | 이유 |
| --- | --- |
| `403` | `CREATE_POST` 권한이 없습니다. |

```ts
await $API.createPostPostsPost({
    body: {
        title: "11월 포인트 이벤트 안내",
        content_data: { kind: "notice", text: "이번 달에는 ..." },
    },
})
```

## 게시글 수정

`PATCH /posts/{post_id}` · SDK `updatePostPostsPostIdPatch`

게시글을 수정합니다. `title`, `content_data`, `poll` 중 **바꾸고 싶은 값만** 보내면 됩니다.

`poll`은 보내는 방법에 따라 다르게 동작합니다. 게시글과 설문은 **같은 트랜잭션**에서 처리되므로, 설문 저장이 실패하면 제목·본문 수정도 함께 취소됩니다.

| `poll` | 동작 |
| --- | --- |
| 보내지 않음 | 설문을 그대로 둡니다. |
| [설문 내용](#설문-내용) 객체 | 설문을 만들거나 수정합니다. 규칙은 [설문 저장](#설문-저장)과 같습니다. |
| `null` | 설문과 응답을 삭제합니다. 설문이 없어도 오류가 나지 않습니다. |

| 오류 | 이유 |
| --- | --- |
| `403` | 작성자가 아니고 `MANAGE_POST` 권한도 없습니다. |
| `404` | 게시글이 없습니다. |
| `409` | 응답이 있는 설문의 선택지를 바꾸려 했거나, 여러 개를 고른 응답이 있는데 복수 선택을 끄려 했습니다. |

```ts
await $API.updatePostPostsPostIdPatch({
    path: { post_id: 12 },
    body: { title: "[수정] 11월 포인트 이벤트 안내" },
})
```

```ts
// 설문 삭제와 제목 수정을 한 번에
await $API.updatePostPostsPostIdPatch({
    path: { post_id: 12 },
    body: { title: "[수정] 11월 포인트 이벤트 안내", poll: null },
})
```

## 게시글 삭제

`DELETE /posts/{post_id}` · SDK `deletePostPostsPostIdDelete`

게시글을 삭제합니다. 작성자 또는 `MANAGE_POST` 권한이 있는 사람만 삭제할 수 있습니다.

**응답** `204` — 본문이 없습니다.

## 설문

게시글 하나에 **객관식 질문 하나**를 붙일 수 있습니다. 학생은 공지 상세 화면에서 응답하고, 결과는 작성자와 `MANAGE_POST` 권한이 있는 사람만 볼 수 있습니다.

- 응답한 사람이 누구인지는 어떤 API로도 내보내지 않습니다. 서버는 중복 응답을 막기 위해서만 응답자를 기록합니다.
- 마감 시각이 지나면 응답하거나 응답을 바꾸거나 취소할 수 없습니다.
- 게시글을 삭제하면 설문과 응답도 함께 삭제됩니다.

### 설문 내용

[게시글 작성](#게시글-작성)의 `poll`과 [설문 저장](#설문-저장)의 본문에 사용합니다.

| 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| `question` | 문자 | ○ | 질문 (1~200자) |
| `options` | 문자 배열 | ○ | 선택지 (2~10개, 각 1~100자, 중복 불가). 배열 순서대로 표시됩니다. |
| `allow_multiple` | 참/거짓 | | 여러 개 선택 허용 여부 (기본값 `false`) |
| `closes_at` | 날짜 | | 마감 시각. 없으면 마감 없이 계속 응답을 받습니다. |

```ts
await $API.createPostPostsPost({
    body: {
        title: "체육대회 점심 메뉴 설문",
        content_data: { kind: "notice", text: "원하는 메뉴를 골라 주세요." },
        poll: {
            question: "체육대회 날 점심 메뉴로 무엇이 좋을까요?",
            options: ["김밥", "샌드위치", "비빔밥"],
            allow_multiple: false,
            closes_at: "2026-11-26T18:00:00+09:00",
        },
    },
})
```

<Callout type="info">
    SDK 타입에서 `closes_at`은 `Date`로 표시되지만, 요청 검증은 ISO 문자열로 합니다. `new Date(...).toISOString()`처럼 **문자열로 보내야** 합니다.
    응답의 `closes_at`도 실제로는 문자열이므로 `new Date(value)`로 바꿔 사용합니다.
</Callout>

### 설문 정보

```json
{
    "post_id": 12,
    "question": "체육대회 날 점심 메뉴로 무엇이 좋을까요?",
    "allow_multiple": false,
    "closes_at": "2026-11-26T18:00:00+09:00",
    "closed": false,
    "options": [
        { "id": 31, "text": "김밥", "votes": 12 },
        { "id": 32, "text": "샌드위치", "votes": 7 },
        { "id": 33, "text": "비빔밥", "votes": null }
    ],
    "my_option_ids": [31],
    "voter_count": 19
}
```

| 항목 | 설명 |
| --- | --- |
| `closed` | 마감되었는지 여부입니다. |
| `options[].votes` | 선택지를 고른 인원 수입니다. 작성자와 `MANAGE_POST` 권한자에게만 채워지고, 그 외에는 `null`입니다. |
| `my_option_ids` | 요청한 사람이 고른 선택지 ID입니다. 응답하지 않았으면 빈 배열입니다. |
| `voter_count` | 응답한 사람 수입니다. `votes`와 같은 조건으로만 채워집니다. 복수 선택 설문에서는 `votes`의 합보다 작을 수 있습니다. |

### 설문 조회

`GET /posts/{post_id}/poll` · SDK `getPollPostsPostIdPollGet`

게시글의 설문과 내 응답을 가져옵니다. [게시글 정보](#게시글-정보)의 `has_poll`이 `true`일 때만 호출하면 됩니다.

| 오류 | 이유 |
| --- | --- |
| `403` | `VIEW_POST` 권한이 없고, 작성자나 `MANAGE_POST` 권한자도 아닙니다. |
| `404` | 게시글이나 설문이 없습니다. |

### 설문 저장

`PUT /posts/{post_id}/poll` · SDK `setPollPostsPostIdPollPut`

설문이 없으면 만들고, 있으면 [설문 내용](#설문-내용)으로 수정합니다. 응답으로 결과가 포함된 [설문 정보](#설문-정보)를 돌려줍니다.
제목·본문과 함께 바꾸려면 [게시글 수정](#게시글-수정)의 `poll`을 사용합니다.

응답이 있는 설문은 이미 고른 선택지의 의미가 바뀌지 않도록 **선택지를 바꿀 수 없고**, 질문·마감 시각·복수 선택 여부만 바꿀 수 있습니다. 마감 시각을 지난 시각으로 바꾸면 바로 마감됩니다.

| 오류 | 이유 |
| --- | --- |
| `403` | 작성자가 아니고 `MANAGE_POST` 권한도 없습니다. |
| `404` | 게시글이 없습니다. |
| `409` | 응답이 있는 설문의 선택지를 바꾸려 했거나, 여러 개를 고른 응답이 있는데 복수 선택을 끄려 했습니다. |
| `422` | [설문 내용](#설문-내용)의 조건(선택지 개수, 길이, 중복 등)에 맞지 않습니다. |

### 설문 삭제

`DELETE /posts/{post_id}/poll` · SDK `deletePollPostsPostIdPollDelete`

설문과 **모든 응답**을 삭제합니다. 되돌릴 수 없습니다.

**응답** `204` — 본문이 없습니다.

| 오류 | 이유 |
| --- | --- |
| `403` | 작성자가 아니고 `MANAGE_POST` 권한도 없습니다. |
| `404` | 게시글이나 설문이 없습니다. |

### 설문 응답

`PUT /posts/{post_id}/poll/vote` · SDK `votePollPostsPostIdPollVotePut`

고른 선택지를 저장합니다. 이미 응답했다면 새 선택으로 바꿉니다. 응답으로 [설문 정보](#설문-정보)를 돌려줍니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `option_ids` | 숫자 배열 | ○ | 고른 선택지 ID (1~10개) |

| 오류 | 이유 |
| --- | --- |
| `400` | 마감되었거나, 이 설문의 선택지가 아니거나, 복수 선택이 꺼져 있는데 여러 개를 골랐습니다. |
| `403` | `VIEW_POST` 권한이 없습니다. |
| `404` | 게시글이나 설문이 없습니다. |

```ts
await $API.votePollPostsPostIdPollVotePut({
    path: { post_id: 12 },
    body: { option_ids: [31] },
})
```

### 설문 응답 취소

`DELETE /posts/{post_id}/poll/vote` · SDK `cancelPollVotePostsPostIdPollVoteDelete`

내 응답을 지웁니다. 응답하지 않은 상태에서 호출해도 오류 없이 끝납니다.

**응답** `204` — 본문이 없습니다.

| 오류 | 이유 |
| --- | --- |
| `400` | 마감된 설문입니다. |
| `403` | `VIEW_POST` 권한이 없습니다. |
| `404` | 게시글이나 설문이 없습니다. |
