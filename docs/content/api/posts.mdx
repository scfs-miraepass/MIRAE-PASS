# 게시글

<Callout type="warning">
    해당 기능은 개발이 완료되지 않은 기능입니다. 이에 따라 API가 변경될 수 있습니다.
</Callout>

공지사항 같은 게시글을 다루는 API입니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `GET` | `/posts` | [게시글 목록](#게시글-목록) | `VIEW_POST` |
| `GET` | `/posts/{post_id}` | [게시글 조회](#게시글-조회) | `VIEW_POST` |
| `POST` | `/posts` | [게시글 작성](#게시글-작성) | `CREATE_POST` |
| `PATCH` | `/posts/{post_id}` | [게시글 수정](#게시글-수정) | 작성자 또는 `MANAGE_POST` |
| `DELETE` | `/posts/{post_id}` | [게시글 삭제](#게시글-삭제) | 작성자 또는 `MANAGE_POST` |

## 게시글 정보

```json
{
    "id": 12,
    "title": "11월 포인트 이벤트 안내",
    "views": 0,
    "created_at": "2026-11-01T09:00:00+09:00",
    "updated_at": "2026-11-02T10:30:00+09:00",
    "author_id": 4001
}
```

| 항목 | 설명 |
| --- | --- |
| `views` | 조회수입니다. |
| `created_at` | 작성한 시간입니다. |
| `updated_at` | 마지막으로 수정한 시간입니다. |
| `author_id` | 작성자의 ID입니다. |

<Callout type="warning">
    현재 게시글을 조회하는 API의 응답에는 **본문(`content_data`)이 포함되지 않습니다.** 작성·수정할 때 보낸 본문은 서버에 저장되지만, 조회 응답에는 제목과 작성 정보만 들어 있습니다.
</Callout>

## 게시글 목록

`GET /posts` · SDK `getPostsPostsGet`

게시글을 **최신순**으로 가져옵니다. 응답 헤더 `X-MAX-PAGE`에 전체 페이지 수가 들어 있습니다.

| 위치 | 이름 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `page` | 숫자 | 1 | 페이지 번호 (1부터 시작) |
| 쿼리 | `size` | 숫자 | 20 | 한 페이지의 게시글 수 (1~100) |

```ts
const req = await $API.getPostsPostsGet({ query: { page: 1, size: 10 } })
const posts = req.data?.data ?? []
const maxPage = Number(req.response?.headers.get("X-MAX-PAGE"))
```

## 게시글 조회

`GET /posts/{post_id}` · SDK `getPostPostsPostIdGet`

게시글 하나의 정보를 가져옵니다. 없으면 `404`로 응답합니다.

```ts
await $API.getPostPostsPostIdGet({ path: { post_id: 12 } })
```

## 게시글 작성

`POST /posts` · SDK `createPostPostsPost`

새 게시글을 작성합니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `title` | 문자 | ○ | 제목 |
| 본문 | `content_data` | 객체(JSON) | ○ | 본문 내용입니다. 글자뿐 아니라 굵게, 이미지 같은 꾸밈 정보도 담을 수 있도록 JSON 객체로 저장합니다. |

**응답** `201` — 작성된 [게시글 정보](#게시글-정보)를 돌려줍니다.

| 오류 | 이유 |
| --- | --- |
| `403` | `CREATE_POST` 권한이 없습니다. |

```ts
await $API.createPostPostsPost({
    body: {
        title: "11월 포인트 이벤트 안내",
        content_data: { text: "이번 달에는 ..." },
    },
})
```

## 게시글 수정

`PATCH /posts/{post_id}` · SDK `updatePostPostsPostIdPatch`

게시글을 수정합니다. `title`, `content_data` 중 **바꾸고 싶은 값만** 보내면 됩니다.

| 오류 | 이유 |
| --- | --- |
| `403` | 작성자가 아니고 `MANAGE_POST` 권한도 없습니다. |
| `404` | 게시글이 없습니다. |

```ts
await $API.updatePostPostsPostIdPatch({
    path: { post_id: 12 },
    body: { title: "[수정] 11월 포인트 이벤트 안내" },
})
```

## 게시글 삭제

`DELETE /posts/{post_id}` · SDK `deletePostPostsPostIdDelete`

게시글을 삭제합니다. 작성자 또는 `MANAGE_POST` 권한이 있는 사람만 삭제할 수 있습니다.

**응답** `204` — 본문이 없습니다.
