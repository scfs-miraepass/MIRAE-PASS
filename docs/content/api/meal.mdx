# 급식

학교 **급식(아침 · 점심 · 저녁) 식단**을 보여줍니다.
급식 정보는 서버가 [NEIS 교육정보 개방 포털](https://open.neis.go.kr)에서 받아 와 전달합니다. 앱이 NEIS를 직접 호출하지 않습니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `GET` | `/meal` | [급식 조회](#급식-조회) | `VIEW_MEAL` |

## 급식 조회

`GET /meal` · SDK `getMealsMealGet`

해당 날짜의 급식을 가져옵니다. 아침 → 점심 → 저녁 순서이며, 급식이 없는 날(주말, 방학 등)은 빈 목록입니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `date` | 문자열 (`YYYY-MM-DD`) | | 조회할 날짜. 생략하면 학교 기준(한국 시간) 오늘입니다. |

**응답** `200`

```json
{
    "success": true,
    "data": [
        {
            "type": "breakfast",
            "dishes": [
                { "name": "쌀밥", "allergies": [] },
                { "name": "닭개장", "allergies": [15] },
                { "name": "고기만두", "allergies": [1, 5, 6, 10] }
            ],
            "calorie": 848.3
        }
    ]
}
```

| 항목 | 설명 |
| --- | --- |
| `type` | 급식 종류입니다. `breakfast`(아침), `lunch`(점심), `dinner`(저녁) 중 하나이며, SDK에서는 `MealType` 상수로 사용할 수 있습니다. |
| `dishes` | 메뉴 목록입니다. 식단표 순서 그대로입니다. |
| `dishes[].name` | 메뉴 이름입니다. |
| `dishes[].allergies` | 알레르기 유발 식품 번호입니다. 아래 [알레르기 번호](#알레르기-번호)를 참고하세요. |
| `calorie` | 열량(kcal)입니다. NEIS에 정보가 없으면 `null`입니다. |

| 오류 | 이유 |
| --- | --- |
| `400` | 존재하지 않는 날짜입니다. (예: `2026-02-30`) |
| `403` | `VIEW_MEAL` 권한이 없습니다. |
| `422` | `date`가 `YYYY-MM-DD` 형식이 아닙니다. |
| `502` | NEIS에서 급식 정보를 가져오지 못했습니다. |

<Callout type="info">
    급식 정보는 날짜별로 최대 1시간 동안 캐시됩니다. 학교에서 NEIS 식단을 고친 경우 최대 1시간 뒤에 반영됩니다.
</Callout>

```ts
const req = await $API.getMealsMealGet({ query: { date: "2026-11-26" } })
if (!req.error) {
    const lunch = req.data.data.find((meal) => meal.type === MealType.LUNCH)
}
```
