# 스티커

**스티커**는 서비스 계정이 학생 · 교사에게 주는 칭찬 표시입니다. 학생은 받은 스티커로 개인 순위와 학급 순위를 겨루고, 교사는 받은 스티커를 원하는 학급에 전달할 수 있습니다.

| 방법 | 경로 | 설명 | 필요한 권한 |
| --- | --- | --- | --- |
| `POST` | `/sticker` | [스티커 지급](#스티커-지급) | `GIVE_STICKER` 또는 `MANAGE_STICKER` |
| `POST` | `/sticker/bulk` | [스티커 일괄 지급](#스티커-일괄-지급) | `GIVE_STICKER` 또는 `MANAGE_STICKER` |
| `POST` | `/sticker/revoke` | [스티커 회수](#스티커-회수) | `MANAGE_STICKER` |
| `POST` | `/sticker/class` | [학급에 스티커 전달](#학급에-스티커-전달) | `GIVE_CLASS_STICKER` |
| `POST` | `/sticker/reset` | [스티커 수동 초기화](#스티커-수동-초기화) | `MANAGE_STICKER` |
| `GET` | `/sticker/me` | [내 스티커 보유 수](#내-스티커-보유-수) | `VIEW_STICKER` |
| `GET` | `/sticker/users/{user_id}` | [유저 스티커 보유 수](#유저-스티커-보유-수) | `GIVE_STICKER` 또는 `MANAGE_STICKER` |
| `GET` | `/sticker/ranking` | [개인 순위](#개인-순위) | `VIEW_STICKER` |
| `GET` | `/sticker/ranking/class` | [학급 순위](#학급-순위) | `VIEW_STICKER` |
| `GET` | `/sticker/history` | [스티커 기록](#스티커-기록) | `MANAGE_STICKER` |
| `DELETE` | `/sticker/history/{history_id}` | [스티커 기록 취소](#스티커-기록-취소) | `MANAGE_STICKER` |

## 보유 수와 집계 기간

보유 수는 따로 저장하지 않고, **현재 집계 기간** 동안의 기록을 더해서 계산합니다.

- 집계 기간은 **매월 1일 00:00(한국 시간)** 에 새로 시작합니다.
- 관리자가 [수동 초기화](#스티커-수동-초기화)를 하면 그 시각부터 새 기간이 시작됩니다.
- 기간이 바뀌어도 기록은 지워지지 않습니다. 이전 기간의 기록은 보유 수와 순위에 더해지지 않을 뿐입니다.

### 주간 한도

지급 한도는 보유 수가 아니라 **이번 주에 받은 수**로 정합니다.

- 한 명이 **한 주(월요일 00:00 한국 시간 ~)** 에 받을 수 있는 스티커는 최대 **3개**입니다.
- 주가 바뀌면 다시 3개까지 받을 수 있고, 받은 스티커는 집계 기간 동안 계속 쌓입니다. (예: 한 달 동안 최대 12~15개 보유 가능)
- [수동 초기화](#스티커-수동-초기화)가 이번 주 중간에 있었다면, 그 시각부터 다시 셉니다.
- [회수](#스티커-회수)하면 이번 주에 받은 수도 함께 줄어 그만큼 다시 받을 수 있습니다.
- 교사의 [학급 전달](#학급에-스티커-전달)은 교사의 보유 수만 줄이고, 이번 주에 받은 수에는 영향을 주지 않습니다.

보유 수를 돌려주는 API는 아래 형태(`StickerBalance`)로 응답합니다.

```json
{
    "success": true,
    "data": {
        "user_id": 1101,
        "count": 5,
        "max": 3,
        "period_start": "2026-11-01T00:00:00+09:00",
        "week_count": 2,
        "week_start": "2026-11-16T00:00:00+09:00"
    }
}
```

| 항목 | 설명 |
| --- | --- |
| `user_id` | 유저 ID입니다. |
| `count` | 현재 집계 기간의 보유 수입니다. |
| `max` | 한 주에 받을 수 있는 최대 수입니다. |
| `period_start` | 현재 집계 기간이 시작된 시각입니다. |
| `week_count` | 이번 주에 받은 수입니다. (학급 전달 제외) |
| `week_start` | 이번 주 한도를 세기 시작한 시각입니다. 월요일 00:00이거나, 그 뒤에 수동 초기화가 있었다면 초기화 시각입니다. |

## 스티커 지급

`POST /sticker` · SDK `grantSticker`

학생 또는 교사에게 스티커를 지급합니다. 지급 후 [이번 주에 받은 수](#주간-한도)가 3개를 넘으면 지급할 수 없습니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `user_id` | 숫자 | ○ | 받을 유저의 ID |
| 본문 | `amount` | 숫자 | | 지급할 수 (1~3, 기본 1) |
| 본문 | `memo` | 문자열 | | 메모 (최대 100자) |

**응답** `200` — 지급 후 [보유 수](#보유-수와-집계-기간)

| 오류 | 이유 |
| --- | --- |
| `400` | 받을 유저가 학생 또는 교사가 아닙니다. |
| `403` | 권한이 없습니다. |
| `404` | 받을 유저가 없습니다. |
| `409` | 이번 주 한도(3개)를 넘습니다. |

```ts
const req = await $API.grantSticker({ body: { user_id: 1101, amount: 1 } })
if (req.error) {
    toast.add({ title: "지급하지 못했어요.", description: req.error.message, color: "error" })
}
```

## 스티커 일괄 지급

`POST /sticker/bulk` · SDK `grantStickers`

여러 학생 또는 교사에게 스티커를 한 번에 지급합니다. [단건 지급](#스티커-지급)과 달리 한도를 넘는 요청을 거부하지 않고, 줄 수 있는 만큼 지급합니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `user_ids` | 숫자 배열 | ○ | 받을 유저의 ID 목록 (1~100명, 중복은 한 번만 처리) |
| 본문 | `amount` | 숫자 | | 한 명마다 지급할 최대 수 (1~3, 기본 1) |
| 본문 | `memo` | 문자열 | | 메모 (최대 100자) |

유저마다 따로 처리하므로 **일부만 성공할 수 있습니다.**

- 이번 주 남은 한도가 `amount`보다 적은 유저에게는 **남은 한도만큼만** 지급합니다. (예: 이번 주 2개를 받은 학생에게 3개를 요청하면 1개 지급) 실제 지급 수는 `granted`로 알려줍니다.
- 남은 한도가 없거나 찾을 수 없는 유저는 건너뛰고 `failed`에 이유를 담습니다.
- 전부 실패해도 상태 코드는 `200`입니다. 결과는 본문에서 확인합니다.

**응답** `200`

```json
{
    "success": true,
    "data": {
        "succeeded": [
            { "user_id": 1102, "count": 3, "max": 3, "period_start": "2026-11-01T00:00:00+09:00", "week_count": 3, "week_start": "2026-11-16T00:00:00+09:00", "granted": 1 }
        ],
        "failed": [
            { "user_id": 1101, "reason": "이번 주 한도(3개)를 넘을 수 없습니다. (이번 주 3개 받음)" },
            { "user_id": 99999, "reason": "유저를 찾을 수 없습니다." }
        ]
    }
}
```

| 항목 | 설명 |
| --- | --- |
| `succeeded` | 지급에 성공한 유저의 지급 후 [보유 수](#보유-수와-집계-기간) 목록입니다. `granted`는 실제 지급된 수로, 남은 한도 때문에 `amount`보다 작을 수 있습니다. |
| `failed` | 지급하지 못한 유저의 ID와 이유입니다. |

| 오류 | 이유 |
| --- | --- |
| `403` | 권한이 없습니다. |
| `422` | `user_ids`가 비어 있거나 100명을 넘습니다. |

```ts
const req = await $API.grantStickers({ body: { user_ids: [1101, 1102], amount: 1 } })
if (!req.error && req.data.data.failed.length > 0) {
    toast.add({ title: `${req.data.data.failed.length}명은 지급하지 못했어요.`, color: "warning" })
}
```

## 스티커 회수

`POST /sticker/revoke` · SDK `revokeSticker`

유저의 스티커를 회수합니다. 요청 본문은 [스티커 지급](#스티커-지급)과 같으며, 보유 수보다 많이 회수할 수 없습니다.

**응답** `200` — 회수 후 [보유 수](#보유-수와-집계-기간)

| 오류 | 이유 |
| --- | --- |
| `400` | 대상 유저가 학생 또는 교사가 아닙니다. |
| `403` | 권한이 없습니다. |
| `404` | 대상 유저가 없습니다. |
| `409` | 보유 수보다 많이 회수하려고 했습니다. |

## 학급에 스티커 전달

`POST /sticker/class` · SDK `giveStickerToClass`

교사가 받은 스티커를 원하는 학급에 전달합니다. 전달한 만큼 교사의 보유 수가 줄고, [학급 순위](#학급-순위)의 합계에 더해집니다. 교사의 [이번 주에 받은 수](#주간-한도)는 바뀌지 않습니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 본문 | `grade` | 숫자 | ○ | 학년 (1~3) |
| 본문 | `number` | 숫자 | ○ | 반 |
| 본문 | `amount` | 숫자 | | 전달할 수 (1~3, 기본 1) |
| 본문 | `memo` | 문자열 | | 메모 (최대 100자) |

**응답** `200` — 전달 후 교사의 [보유 수](#보유-수와-집계-기간)

| 오류 | 이유 |
| --- | --- |
| `403` | 권한이 없습니다. |
| `404` | 해당 학급에 학생이 없습니다. |
| `409` | 보유한 스티커가 부족합니다. |

## 스티커 수동 초기화

`POST /sticker/reset` · SDK `resetStickers`

새 집계 기간을 시작해 모든 유저의 보유 수를 0으로 만듭니다. 기록은 지워지지 않습니다.

**응답** `204` — 본문이 없습니다.

<Callout type="warning">
    초기화는 되돌릴 수 없습니다. 초기화 이전의 기록은 [스티커 기록](#스티커-기록)에서도 더 이상 보이지 않습니다.
</Callout>

## 내 스티커 보유 수

`GET /sticker/me` · SDK `getMyStickerBalance`

로그인한 유저의 [보유 수](#보유-수와-집계-기간)를 가져옵니다. 학생 또는 교사가 아니면 `count`는 항상 `0`입니다.

## 유저 스티커 보유 수

`GET /sticker/users/{user_id}` · SDK `getUserStickerBalance`

다른 유저의 [보유 수](#보유-수와-집계-기간)를 가져옵니다. 지급하기 전에 이번 주 남은 한도(`max - week_count`)를 보여줄 때 사용합니다.

| 오류 | 이유 |
| --- | --- |
| `403` | 권한이 없습니다. |
| `404` | 유저가 없습니다. |

## 개인 순위

`GET /sticker/ranking` · SDK `getStickerRanking`

현재 집계 기간의 보유 수 기준 **학생** 순위를 가져옵니다. 같은 수이면 같은 순위입니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `q` | 문자열 | | 검색어 (이름, 초성 또는 4자리 학번) |
| 쿼리 | `limit` | 숫자 | | 페이지 당 개수 (1~100, 기본 20) |
| 쿼리 | `offset` | 숫자 | | 건너뛸 개수 (기본 0) |

전체 페이지 수는 `X-MAX-PAGE` 헤더로 알려줍니다. 검색해도 `rank`는 **전체 학생 기준 순위**입니다.

```json
{
    "success": true,
    "data": [
        { "id": 1101, "name": "홍길동", "grade": 1, "number": 1, "count": 5, "week_count": 2, "rank": 1 }
    ]
}
```

| 항목 | 설명 |
| --- | --- |
| `count` | 현재 집계 기간의 보유 수입니다. 순위는 이 값 기준입니다. |
| `week_count` | 이번 주에 받은 수입니다. 화면에서 [주간 한도](#주간-한도) 하트를 채우는 데 사용합니다. |

## 학급 순위

`GET /sticker/ranking/class` · SDK `getStickerClassRanking`

학급별 스티커 합계를 가져옵니다. 합계는 **학급 학생들의 보유 수 + 교사가 전달한 수**입니다.
목록은 1학년 1반부터 학년, 반 순서이며, `rank`는 합계 기준 순위입니다.

```json
{
    "success": true,
    "data": [
        { "grade": 1, "number": 1, "count": 7, "teacher_count": 2, "rank": 1 }
    ]
}
```

| 항목 | 설명 |
| --- | --- |
| `count` | 학급 합계입니다. |
| `teacher_count` | 그중 교사가 전달한 수입니다. |
| `rank` | 합계 기준 순위입니다. |

## 스티커 기록

`GET /sticker/history` · SDK `getStickerHistory`

현재 집계 기간의 지급 · 회수 · 학급 전달 기록을 최신순으로 가져옵니다.

| 위치 | 이름 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- | --- |
| 쿼리 | `user_id` | 숫자 | | 이 유저의 기록만 가져옵니다. |
| 쿼리 | `limit` | 숫자 | | 페이지 당 개수 (1~100, 기본 20) |
| 쿼리 | `offset` | 숫자 | | 건너뛸 개수 (기본 0) |

전체 페이지 수는 `X-MAX-PAGE` 헤더로 알려줍니다.

```json
{
    "success": true,
    "data": {
        "period_start": "2026-11-01T00:00:00+09:00",
        "items": [
            {
                "id": 12,
                "user_id": 4001,
                "amount": -1,
                "actor_id": 4001,
                "memo": null,
                "class_grade": 1,
                "class_number": 2,
                "created_at": "2026-11-15T09:30:00+09:00",
                "user": { "id": 4001, "type": "teacher", "name": "김선생", "grade": null, "number": null },
                "actor": { "id": 4001, "type": "teacher", "name": "김선생", "grade": null, "number": null }
            }
        ]
    }
}
```

| 항목 | 설명 |
| --- | --- |
| `amount` | 변동 수입니다. 지급은 양수, 회수와 학급 전달은 음수입니다. |
| `class_grade`, `class_number` | 학급 전달 기록이면 전달한 학급, 아니면 `null`입니다. |
| `user` | 대상 유저 요약 정보(`id`, `type`, `name`, `grade`, `number`)입니다. |
| `actor` | 처리한 유저 요약 정보입니다. 처리한 유저가 삭제되었으면 `null`입니다. |

## 스티커 기록 취소

`DELETE /sticker/history/{history_id}` · SDK `deleteStickerHistory`

기록 하나를 지워 그 변동을 없던 것으로 만듭니다.
현재 집계 기간의 기록을 지웠을 때 대상 유저의 보유 수가 0보다 작아지면 취소할 수 없습니다. (예: 교사가 이미 학급에 전달한 스티커의 지급 기록)

**응답** `204` — 본문이 없습니다.

| 오류 | 이유 |
| --- | --- |
| `403` | 권한이 없습니다. |
| `404` | 기록이 없습니다. |
| `409` | 취소하면 보유 수가 0보다 작아집니다. |
